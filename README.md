👥 Users App

Users App is a web application for managing a list of users using a REST API powered by MockAPI. The project demonstrates working with arrays and implementing core CRUD operations (Create, Read, Update, Delete).

🚀 Features
📥 Fetch users from the server
➕ Create a new user
✏️ Edit existing user data
❌ Delete a user
🔄 Automatically update the UI after operations
📊 Array manipulation (map, filter, find, etc.)
🛠️ Tech Stack
HTML5
CSS3
JavaScript (ES6+)
REST API
MockAPI
⚙️ Implementation Details
Asynchronous requests using fetch and async/await
Proper API error handling
Dynamic rendering of user data
Clean and maintainable code structure
State management via JavaScript arrays
